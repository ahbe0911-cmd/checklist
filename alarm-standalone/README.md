# آلارم مستقل | Standalone Android Alarm

این یک پروژه Android/Kotlin مستقل است. برای ساخت و نصب به کد چک‌لیست، یادداشت‌ها یا برنامه میزبان نیاز ندارد.

## مشخصات
- شناسه نصب: `com.ahbe.alarm`
- زبان: Kotlin و رابط کاربری Native Android
- حداقل اندروید: 8.0 (API 26)، targetSdk 34
- ورودی اصلی: `com.ahbe.alarm.MainActivity`
- مسیر پروژه: `alarm-standalone/`
- خروجی: `alarm-standalone/app/build/outputs/apk/debug/app-debug.apk`

## قابلیت‌ها
- آلارم معمولی: یک‌بار، روزانه، روزهای منتخب، هفتگی، ماهانه و سالانه شمسی
- تاریخ شروع و پایان شمسی، سقف تعداد زنگ‌ها و رفتار روزهای مفقود ماه
- آلارم طلوع خورشید، انتخاب مکان با مختصات/نقشه/موقعیت گوشی و فاصله زمانی نسبت به طلوع
- هشت ملودی تولیدشده درون برنامه، فایل صوتی دلخواه، ضبط صدای کاربر و پیش‌نمایش
- لرزش، افزایش تدریجی صدا، تعویق ۵/۱۰/۱۵ دقیقه، صفحه زنگ قابل نمایش روی قفل و اعلان
- بازگردانی زمان‌بندی بعد از راه‌اندازی مجدد گوشی و تغییر ساعت/منطقه زمانی
- صفحه تنظیمات با وضعیت واقعی مجوزهای سیستم و تست زنگ پس از ۱۵ ثانیه

## ساخت پروژه
از داخل پوشه `alarm-standalone` دستور زیر را اجرا کنید:

```bash
gradle --no-daemon :app:assembleDebug
```

یا فایل APK مستقل را از GitHub Actions با نام `alarm-standalone-debug-apk` دریافت کنید. Android SDK 35، Java 17 و Gradle 8.9 لازم است.

## مجوزها
برای عملکرد قابل‌اعتماد آلارم، در اندرویدهای جدید مجوزهای **آلارم دقیق**، **اعلان‌ها** و در صورت پشتیبانی، **نمایش تمام‌صفحه** باید از تنظیمات گوشی فعال باشند. مکان برای آلارم طلوع و میکروفون برای ضبط صدای شخصی اختیاری هستند. دسترسی اینترنت برای نمایش نقشه استفاده می‌شود؛ محاسبه خود طلوع آفلاین است.

## استقلال داده‌ها
این اپ شناسه نصب و فضای ذخیره‌سازی جداگانه دارد. آلارم‌های ذخیره‌شده در برنامه چک‌لیست **به‌صورت خودکار** منتقل نمی‌شوند. هدف از جداسازی جلوگیری از هرگونه تغییر ناخواسته در داده‌ها و زمان‌بندی برنامه قدیمی است.

## محدودیت‌های آزمون
ساخت موفق APK لزوماً به معنای تأیید همه سناریوهای گوشی نیست. آزمون روی دستگاه واقعی با صفحه قفل، حالت Doze، مجوزها، جلوگیری از فعالیت پس‌زمینه و راه‌اندازی مجدد دستگاه ضروری است.

## طراحی
برای ادامه توسعه و طراحی نسخه تجاری، سند `PROMPT_FA.md` را بخوانید.

## نسخه جدید رابط کاربری (Add Alarm / Sunrise Location)

- فرم افزودن و ویرایش دارای کارت‌بندی موضوعی، فیلدهای خاکستری بدون خط زیر، دکمه‌های دایره‌ای انتخاب روز و کنترل‌های روشن/خاموش استاندارد است.
- صفحه موقعیت طلوع، در حالت پیش‌فرض فقط دکمه «تشخیص موقعیت من» و نام مکان شناسایی‌شده را نشان می‌دهد؛ ورود دستی مختصات و منطقه زمانی در «تنظیمات پیشرفته» پنهان است.
- نام مکان با Android Geocoder در یک Thread غیر از رابط کاربری دریافت می‌شود. در صورت نبود سرویس نام‌گذاری، «موقعیت انتخاب‌شده» نمایش داده می‌شود و هیچ شهر ساختگی نمایش داده نمی‌شود.
- هیچ داده‌ای با تشخیص موقعیت ذخیره نمی‌شود تا کاربر «تأیید موقعیت» را بزند.
- منطق AlarmStore، AlarmScheduler و SolarMath به‌خاطر این بازطراحی تغییر نکرده‌اند.

## استفاده از فونت‌های سفارشی ارسالی

در حالت پیش‌فرض Vazirmatn با نام `assets/fonts/far_vazir.ttf` توسط workflow دریافت می‌شود. اگر مجوز استفاده از فونت‌های سفارشی روی محصول را دارید، آنها را در پروژه محلی قرار دهید:

- فایل `Far_TitrBd.ttf` در `alarm-standalone/app/src/main/assets/fonts/Far_TitrBd.ttf` برای تیتر پنجره‌ها.
- فایل `A Rooznameh.ttf` را با نام `A_Rooznameh.ttf` در همان پوشه برای نمایش نام موقعیت.

کد هر دو را به‌صورت اختیاری بارگذاری می‌کند و اگر نبودند به Vazirmatn بازمی‌گردد. **فایل‌های آپلودشده فونت در این مخزن عمومی بازنشر نشده‌اند**؛ انتشار فونت‌ها باید مطابق مجوزشان انجام شود.
