# Novi | یادداشت‌های گفت‌وگومحور

**Novi** یک برنامه بومی اندروید برای یادداشت‌نویسی آفلاین است؛ با رابط کاربری فارسی، کارت‌های شبیه حباب چت، سربرگ‌های رنگی و ضبط پیام صوتی. نام و آیکون برنامه به‌روز شده‌اند، ولی شناسه نصب `com.ahbe.checklist` و کلید ذخیره‌سازی `optimized_notes` ثابت مانده‌اند تا داده‌های کاربران نسخه قبلی حفظ شوند.

## آنچه در این نسخه وجود دارد

- افزودن یادداشت متنی با کادر پیام‌رسانی و دکمه ارسال، نمایش یادداشت‌ها در حباب‌های رنگی با انیمیشن ورود.
- بازکردن هر یادداشت به‌صورت صفحه داخلی با زیرشاخه‌های نامحدود؛ ارسال یادداشت‌های زیرمجموعه و حرکت نرم بین صفحه‌ها.
- سربرگ‌های شخصی‌سازی‌شدنی با رنگ و آیکون، جست‌وجوی متن و نمایش میزان تکمیل یادداشت‌ها.
- تکمیل و حذف یادداشت، شمارنده زیرشاخه‌ها، تاریخ اجرای شمسی **بدون اعلان یا زنگ**.
- ضبط و پخش پیام‌های صوتی، انتخاب نام، ذخیره یا اشتراک‌گذاری فایل، عکس و گالری سه‌ستونی.
- پشتیبان‌گیری و بازیابی از داده‌های یادداشت‌ها و فایل‌های آنها.
- بدون اینترنت، بدون موقعیت مکانی، بدون دسترسی تقویم و بدون زمان‌بندی آلارم.

## ساختار کد

- `app/src/main/java/com/ahbe/checklist/MainActivity.kt`: رابط کاربری Kotlin برای فهرست و گفت‌وگوی یادداشت‌ها.
- `app/src/main/res/layout/activity_main.xml`: ریشه XML صفحه بومی اندروید.
- `app/src/main/res/values/colors.xml`: پالت رنگی Novi.
- `app/src/main/res/values/styles.xml`: تم پنجره و سیستم.
- `app/src/main/res/drawable/ic_launcher.xml`: شکل اصلی تیک و خطوط، بدون متن تبلیغاتی.
- `app/src/main/java/com/ahbe/checklist/VoiceRecordingService.kt`: ضبط صوت با سرویس پیش‌زمینه.
- `app/src/main/java/com/ahbe/checklist/UserBackup.kt`: بسته‌بندی و بازیابی داده‌های یادداشت.

سیستم قدیمی زنگ، یادآوری، دریافت مجوز تقویم و ثبت رویداد در تقویم گوشی از برنامه **Novi** حذف شده است. تاریخ اجرای کار صرفاً در خود یادداشت ثبت و نمایش داده می‌شود و اعلان نمی‌سازد. پروژه مستقل آلارم در شاخه توسعه‌ای جداگانه نگهداری می‌شود و جزو APK این برنامه نیست.

## ساخت APK، گام‌به‌گام

۱. **JDK 17**، **Android SDK API 35** و **Gradle 8.9** را نصب کنید. پیش‌نیازهای Gradle در `build.gradle.kts` و `settings.gradle.kts` تعریف شده‌اند.

۲. فایل فونت‌های مورد استفاده را در `app/src/main/assets/fonts/` قرار دهید:
   - `far_vazir.ttf`: Vazirmatn Bold
   - `vazirmatn_regular.ttf`: Vazirmatn Regular
   - `a_rooznameh.ttf`: فونت تاریخ در نسخه اصلی

   گردش‌کار GitHub Actions این فایل‌ها را هنگام ساخت از نشانی‌های تثبیت‌شده تهیه می‌کند. در پروژه محلی در صورت نبود فایل فونت، برنامه از فونت پیش‌فرض اندروید استفاده می‌کند؛ برای اجرای یکسان ظاهر، فونت‌ها باید موجود باشند.

۳. در پوشه اصلی مخزن اجرا کنید:

```bash
gradle :app:assembleDebug --no-daemon
```

۴. APK ساخته‌شده در مسیر زیر قرار می‌گیرد:

```
app/build/outputs/apk/debug/app-debug.apk
```

۵. راه ساده‌تر: از تب GitHub Actions گردش‌کار **Build Native Android APK** را اجرا و پس از موفقیت `novi-notes-debug-apk` را از بخش Artifacts دریافت کنید.

۶. برنامه را روی گوشی نصب کنید و افزودن/حذف یادداشت، جست‌وجو، زیرشاخه، ضبط صدا، اشتراک‌گذاری صوت، عکس، تغییر سربرگ و پشتیبان‌گیری را امتحان کنید.

## نکات سازگاری

- **شناسه نصب تغییر نکرده است.** نصب نسخه جدید روی نسخه قبلی با همان امضای APK و `versionCode` بالاتر، داده‌های کاربران را حفظ می‌کند. اگر نسخه قبلی با کلید امضای متفاوت نصب شده باشد، Android اجازه به‌روزرسانی مستقیم نخواهد داد؛ قبل از جایگزینی حتماً پشتیبان تهیه کنید.
- فایل JSON یادداشت‌های نسخه قبلی خوانده می‌شود؛ فیلدهای قدیمی مربوط به زنگ در مدل جدید دیگر استفاده یا ذخیره نمی‌شوند.
- APK نوع debug برای تست است؛ برای انتشار باید نسخه release امضا و آزمون روی دستگاه واقعی انجام شود.
