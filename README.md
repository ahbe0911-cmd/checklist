# چک‌لیست من

اپلیکیشن فارسی چک‌لیست با تقویم مناسبت‌های ملی و مذهبی ایران، ساخته‌شده با React، Vite و Capacitor.

## قابلیت‌ها
- افزودن، انجام‌شده‌کردن و حذف کارها
- ذخیره محلی کارها در مرورگر / اپلیکیشن
- دریافت مناسبت‌های ماه شمسی جاری
- تفکیک مناسبت‌های ملی و مذهبی
- رابط واکنش‌گرا برای موبایل و دسکتاپ

## اجرای محلی
نیازمند Node.js 22 یا نسخه سازگار است.

```bash
npm install
npm run dev
```

## ساخت APK
در GitHub به بخش **Actions** برو و workflow با نام **Build Android APK** را اجرا کن؛ یا پس از commit شدن workflow، هر push به شاخه main آن را اجرا می‌کند.

پس از موفق‌شدن build:
1. اجرای workflow را در Actions باز کن.
2. به پایین صفحه برو و بخش Artifacts را پیدا کن.
3. فایل `checklist-debug-apk` را دانلود و از حالت ZIP خارج کن.
4. فایل `app-debug.apk` را روی گوشی اندرویدی نصب کن.

این APK نسخه debug است و برای نصب مستقیم و آزمایش مناسب است؛ برای انتشار عمومی در Google Play باید نسخه release امضاشده ساخته شود.
